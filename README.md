# Sistema de Control de Inventario de Repuestos (UNIMAR)

Proyecto desarrollado en Python aplicando la metodología ágil Extreme Programming (XP), control de versiones con Git y gestión de flujo de trabajo mediante ramas e integración vía Pull Requests en GitHub.

## 🛠️ Funcionalidades Implementadas

- **HU-01:** Registrar nuevos repuestos (Código OEM, Nombre, Cantidad) con validaciones de campos vacíos y valores negativos.
- **HU-01:** Visualizar el inventario de repuestos en stock mediante una interfaz en consola formateada.
- **HU-02:** Eliminar repuestos del inventario buscando por su código único de referencia.
